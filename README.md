# Student Course Management System

## Project Overview
The Student Course Management System is a Java console-based application developed for COS201 Programming I.

It allows users to manage student courses by adding, viewing, searching, and calculating course credit units.

## Features
- Add new courses with course code, title, and credit units.
- View all registered courses.
- Search for a course using its course code.
- Calculate total credit units.
- Save course records to a text file.
- Load previously saved course records.
- Validate user input and handle errors.
- Recursive course search.

## Technologies Used
- Java
- Visual Studio Code
- Java ArrayList
- File Handling
- Object-Oriented Programming

## Project Files
- `Main.java` – Main menu and program execution.
- `Course.java` – Course class and attributes.
- `CourseManager.java` – Course management operations.
- `courses.txt` – Saved course records.

## How to Run
1. Install the Java JDK.
2. Open the project folder in Visual Studio Code.
3. Compile the Java files.
4. Run `Main.java`.
